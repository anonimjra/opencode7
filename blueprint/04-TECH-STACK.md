# 04. Tech Stack: Aether OS

| Kategori | Teknologi | Versi | Peran / Alasan |
| :--- | :--- | :--- | :--- |
| **Framework** | Next.js (App Router) | 15.x / Latest | Server-Side Generation (SSG) static export (`output: 'export'`) |
| **Bahasa** | TypeScript | Strict | Keamanan tipe 100%, zero `any`, type contracts ketat |
| **Styling** | Tailwind CSS v4 | v4 (`@import "tailwindcss";`) | Styling utility-first modern dengan warna cyber-industrial kustom |
| **Ikonografi** | Lucide React | Latest | Koleksi icon navigasi, telematika, maritim, dan sensor lengkap |
| **Visualisasi Data** | Recharts | Latest | AreaChart, BarChart, LineChart, RadarChart, ComposedChart |
| **Animasi** | Framer Motion | Latest | Transisi modal, drawer sliding, radar pulse, dan kartu interaktif |
| **State Management**| Zustand | Latest | Manajemen state global ringan dengan middleware `persist` ke LocalStorage |
| **File Export** | ExcelJS | Latest | Pembuatan file Excel (.xlsx) murni di client-side dengan styling sel |
| **Efek Visual** | Canvas-Confetti | Latest | Efek selebrasi saat berhasil memesan shipment baru |
| **Audio Synthesizer**| Web Audio API | Native Browser | Sintesis audio sonar ping dan sirene alarm tanpa file audio eksternal |
